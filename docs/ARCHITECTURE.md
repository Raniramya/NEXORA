# Architecture

Next.js provides Assets & Telemetry, Geo Intelligence, Maintenance Planner, Data, Analytics, ML Lab, Causal Lab, Decision Register, AI Investigator, and Research Evaluation workspaces. FastAPI exposes physical-asset evidence, idempotent edge ingestion, dataset ingestion/profile/analytics, synchronous ML runs, causal/intervention analysis, evidence-bounded decisions, and research evaluation endpoints. PostgreSQL stores physical maintenance records and analytical run metadata; uploaded files, model artifacts, and hashed research reports use local storage boundaries. An MQTT bridge validates device envelopes and forwards them into the same authoritative signal-window API used by HTTP replay. Correlation diagnostics are explicitly labelled non-causal; causal effects originate from the causal service and retain their identification assumptions.

The implementation sequence and integration gates are maintained in `docs/IMPLEMENTATION_PLAN.md`. Raw windows produce versioned features; confirmed labels feed reproducible fault models; permutation-SHAP explains prediction behavior; Isolation Forest scores unknown conditions; maintenance experiments feed DAG-gated causal studies; and an independent calibration partition supports calibrated probabilities, conformal sets, and ACT/MONITOR/ABSTAIN. Geospatial runs compute Haversine distances and descriptive DBSCAN hotspots while preserving asset and fault-event provenance. Evidence-gated binary NSGA-II produces feasible Pareto maintenance options and same-constraint baselines across calibrated risk, declared resources, distance, and identified causal benefit. Integrated decisions reconstruct these predictive, causal, spatial, and optimization branches into a typed provenance graph, abstain on broken links, and require named review before planned actions are created. Physical validation then computes observed intervention benefit from linked pre/post readings, while aligned benchmark and ablation runs generate hashed research artifacts from recorded outputs. All ten implementation phases are integrated; real experimental data collection remains an operational research activity rather than a software-generated claim.
